# 📦 Installation Requirements

Depending on which version of **Simpler Multi-tool** you are running, you will need to install the following Python dependencies.

## 🟢 Simpler_Multi-tool_norV1.4 (Normal)
To install all required packages for the standard edition, run:
```bash
pip install requests Pillow colorama
```

## 🔴 Simpler_Multi-tool_offV1.4 (Offensive)
The offensive edition requires additional libraries for the keylogger and web UI features. To install, run:
```bash
pip install requests Pillow pynput colorama Flask
```
